# Agentfield: An Interactive Guide to AI Agents

Agentfield is a single-page introduction to AI agents. It explains their basic components, compares agents with chatbots and fixed workflows, and gives practical examples of where agents can help.

## Features

- A four-stage, scripted walkthrough for research, software debugging, and data analysis
- A three-question quiz with immediate feedback
- A light/dark theme switch
- Responsive layout and keyboard-friendly navigation

The walkthrough is an educational simulation. It does not connect to an AI model or external service.

## Run locally

Clone the repository and open `index.html` in a modern browser. No installation, build step, account, or API key is required.

```bash
git clone https://github.com/onderbaris/Day-2-Sample.git
cd Day-2-Sample
```

Then open `index.html` in your browser. You can also serve the directory with a local static server if you prefer.

## Project files

- `index.html` — page content and interactive controls
- `style.css` — layout, responsive styling, and themes
- `script.js` — walkthrough, quiz, and theme behavior

The guide remains readable with JavaScript disabled; the interactive features require JavaScript.
